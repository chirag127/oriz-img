oriz Image Studio

A free image toolkit — resize, crop, compress, convert, strip EXIF, and AI alt-text — that runs 100% in your browser. This page describes the project. The live tool is a separate site.

Open the app → Source on GitHub llms.txt

What it is

Image toolkit — resize, crop, compress, convert, EXIF strip, AI alt-text. Point it at any image and get a web-ready file without uploading anything anywhere.

Key features

  • Resize & convert — exact width/height with aspect lock; export WebP, JPEG or PNG.
  • Compress — quality dial to shrink file size while staying sharp.
  • Crop — keep just the region you need before export.
  • Strip EXIF metadata — canvas re-encode drops orientation, GPS and camera data.
  • AI alt-text — accessible descriptions via free in-browser AI, no key.

Tech

  • Client-only Astro static site — no server-side image handling.
  • AI alt-text via g4f through @chirag127/oz-ai (keyless, multi-provider failover).
  • PWA-installable — works offline once loaded.
  • 100% in-browser — no upload, no signup, nothing stored.
